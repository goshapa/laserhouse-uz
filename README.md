# Laser House — сайт

Сайт: https://laserhouse.uz (www и laserhouse.vercel.app тоже работают). Статический сайт без сборки: `index.html` + `assets/`. Открыть можно двойным кликом или через локальный сервер:

```bash
npx http-server -p 5173 -c-1
```

## Где что менять

- **Цены, зоны, FAQ, памятка, противопоказания** — `assets/js/data.js` (`LH.prices`, `LH.faq`, `LH.prep`, `LH.contra`).
- **Ссылки** (онлайн-запись Altegio, Telegram, Instagram, телефон) — `LH.links` в `assets/js/data.js`.
- **Тексты на русском** — прямо в `index.html`; **узбекский перевод** — `LH.uz` в `assets/js/data.js` (ключ = `data-i18n` элемента).
- **Цвета и шрифты** — переменные в начале `assets/css/style.css`.

Цены взяты из онлайн-записи Altegio (октябрь 2026), по филиалу Мирабад.

## Перед запуском в продакшн

- Вычитать узбекскую версию носителем языка.
- Проверить у студии: позиция «Шея полностью» (диод, жен.) стоит 199 999 сум, а «Подбородок» (александрит, муж.) — 1 ч 20 мин. Так указано в Altegio, похоже на опечатки.
- Добавить фото студий и мастеров («до/после» уже есть: `assets/img/results/`).
- Поставить точные координаты филиалов для кнопок «Маршрут».

## Telegram-бот и сертификаты

- Бот: `api/bot.js` (Vercel-функция по вебхуку), модуль сертификатов: `api/_certs.js`.
- Переменные в Vercel: `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET`, `ADMIN_CHAT_ID` (id админов через запятую), `SHEETS_URL`, `SHEETS_SECRET`, `SHEETS_VIEW_URL` (ссылка на таблицу для кнопки у админов), опционально `CERT_VALID_MONTHS` (по умолчанию 12).
- Реестр сертификатов — Google Таблица со скриптом `google-apps-script/Code.gs` (веб-приложение). Секрет в скрипте должен совпадать с `SHEETS_SECRET`.
- Админ: `/create` — создать сертификат, отправить боту код — проверить/погасить, `/certs` — последние, `/sheet` — открыть таблицу.

## Панель ИИ-администратора

`https://laserhouse.uz/ai`: характер и инструкции ИИ, скрипт для Instagram, правила, переключатели каналов, пробный чат и история версий. Вход: администратор отправляет боту `/panel` и открывает одноразовую ссылку (доступ только у `ADMIN_CHAT_ID`). Изменения хранятся в Redis (`ai:cfg`, `ai:settings`, `ai:kb`) и важнее текстов из `api/_agent.js` и `api/_script.md`: блок, изменённый в панели, правками в коде не обновится, пока его не вернут к исходному.
