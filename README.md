# Laser House — сайт

Статический сайт без сборки: `index.html` + `assets/`. Открыть можно двойным кликом или через локальный сервер:

```bash
npx http-server -p 5173 -c-1
```

## Где что менять

- **Цены, зоны, FAQ, памятка, противопоказания** — `assets/js/data.js` (`LH.prices`, `LH.faq`, `LH.prep`, `LH.contra`).
- **Ссылки** (онлайн-запись Altegio, Telegram, Instagram, телефон) — `LH.links` в `assets/js/data.js`.
- **Тексты на русском** — прямо в `index.html`; **узбекский перевод** — `LH.uz` в `assets/js/data.js` (ключ = `data-i18n` элемента).
- **Цвета и шрифты** — переменные в начале `assets/css/style.css`.

Цены взяты из онлайн-записи Altegio (октябрь 2026), по филиалу Мирабад.

## Перед запуском в продакшн

- Вычитать узбекскую версию носителем языка.
- Проверить у студии: позиция «Шея полностью» (диод, жен.) стоит 199 999 сум, а «Подбородок» (александрит, муж.) — 1 ч 20 мин. Так указано в Altegio, похоже на опечатки.
- Добавить реальные фото студий, мастеров и «до/после» (сейчас визуал собран на CSS-графике).
- Поставить точные координаты филиалов для кнопок «Маршрут».
